# Строгий аудит OQY

11 ноября 2026, Asia/Almaty. Исходная версия: `38c4c4e`. Проверка выполнена основным агентом и тремя независимыми подагентами по ECC production-audit, security-review и code-reviewer; браузер дополнительно просмотрен через ECC Chrome DevTools.

**Вердикт: после исправлений пригоден для локальной демонстрации на хакатоне.** Экспертная оценка готовности именно к этому сценарию — 85/100, а не математическая оценка качества или педагогической эффективности. До аудита зелёные 18 тестов не обнаруживали перечисленные ниже дефекты. Для промышленного внедрения этот аудит недостаточен.

## Что остаётся ограничением

- Нет независимых реальных школьных данных и педагогического пилота. Эффективность учебника и влияние перераспределения часов не доказаны.
- Один CSV — один срез; продольные данные и повторные попытки требуют другой схемы. Для локальных школьных ID нужен префикс школы.
- План — эвристика с минимумом 1 час на тему, без предметных нормативов/верхних границ/зависимостей тем. Его утверждает методист.
- Приложение хранит импорт только в памяти вкладки; обновление страницы возвращает демо. Совместная работа, серверное хранение и интеграции не реализованы.
- Проверены Chrome/macOS и GitHub CI/Linux; ручная проверка другими браузерами, скринридером и на Windows не выполнена.
- Монолитный App.tsx усложняет сопровождение; дальнейшую разработку стоит начать с выделения экранов и общего состояния импорта.
- Человек ещё должен отрепетировать устную защиту. Отправку формы и подтверждение приёма организаторов выполняет участник.

Ни одна из этих границ не скрывается за отметкой «тесты зелёные». Открытых воспроизводимых блокеров именно проверенного локального демо после исправлений не осталось.
