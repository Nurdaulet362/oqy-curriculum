# Комплект для формы организаторов

**Название:** OQY — Data-Driven Curriculum.

**Кейс:** 1. Интеллектуальная система оценки эффективности учебников и учебных программ.

**Описание для вставки:** OQY помогает методисту принимать решения на основе результатов тестирования: загружает CSV или Excel (.xlsx), показывает сложные темы, медиану и разброс результатов, сопоставляет учебники по общим разделам и формирует объяснимый план распределения учебных часов с фиксированным бюджетом. Поиск и сортировка помогают работать с темами, сохраняя полный итог и экспорт. Вся обработка выполняется локально в браузере. Демонстрация включает 144 синтетических ученика и 864 результата; сравнение описательное, без утверждений о причинной эффективности учебника.

**Репозиторий:** https://github.com/Nurdaulet362/oqy-curriculum — приватный.

**Стек:** React, TypeScript, Vite, TanStack Table, Papa Parse, read-excel-file, simple-statistics, Vitest, Playwright. Без платных API и отдельного сервера.
