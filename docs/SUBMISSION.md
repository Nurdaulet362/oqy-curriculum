# Комплект для формы организаторов

**Название:** OQY — Data-Driven Curriculum.

**Кейс:** 1. Интеллектуальная система оценки эффективности учебников и учебных программ.

**Описание для вставки:** OQY помогает методисту принимать решения на основе результатов тестирования: загружает CSV, показывает сложные темы, сопоставляет учебники по общим разделам и формирует объяснимый план распределения учебных часов с фиксированным бюджетом. Вся обработка выполняется локально в браузере. Демонстрация включает 144 синтетических ученика и 864 результата; сравнение описательное, без утверждений о причинной эффективности учебника.

**Репозиторий:** https://github.com/Nurdaulet362/oqy-curriculum — приватный.

**Стек:** React, TypeScript, Vite, Papa Parse, Vitest, Playwright. Без платных API и отдельного сервера.
