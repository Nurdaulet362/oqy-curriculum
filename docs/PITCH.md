# Защита OQY — сценарий на 3 минуты

Время 3 минуты выбрано для подготовки: длительность выступления организаторами не указана. При другом лимите сократите вступление и оставьте путь «данные → сложная тема → план → проверка».

## Перед выходом

1. Выполнить `npm run build`, затем `npm run preview`.
2. Открыть приложение по адресу Vite и `/pitch.html` в соседней вкладке.
3. Убедиться, что загружен демонстрационный набор и видна отметка синтетических данных.
4. Подготовить `public/data/template.csv` для показа формата и `public/data/demo.csv` для повторной загрузки.
5. Проверить запуск на том ноутбуке, с которого идёт защита. Не обновлять зависимости перед выходом.
6. Если приложение временно недоступно, открыть `public/pitch.html` напрямую. Это автономные слайды с описанием сценария, а не запись работающего продукта.

## Числа для выступления

На защите называйте только числа из текущего интерфейса и сохранённого отчёта проверки. Не называйте процент улучшения успеваемости, точность прогноза, экономию часов труда или причинный эффект учебника: эти результаты не измерялись.

## Репетиция и резерв

Этот файл — план репетиции, а не свидетельство уже проведённого выступления. Запустите таймер и пройдите таблицу на своей машине; зафиксируйте фактическую длительность. При задержке пропустите загрузку CSV, сохранив сравнение и проверку суммы часов. Презентация автономна; используйте её при сбое приложения и прямо скажите, что показываете описание подготовленного сценария. Если есть сохранённый скриншот, обозначьте его как сохранённый результат.

Короткие ответы на вопросы находятся в [JURY_QA.md](JURY_QA.md).

## Проверка сценария на версии проекта

11 ноября 2026 года выполнен автоматизированный проход браузером Chrome через `node scripts/e2e.mjs`: обзор, детали темы, сравнение учебников, исходный план 34 часа, отклонение бюджета 2 часа, план 40 часов, экспорт JSON и CSV, отклонение неверного CSV с сохранением данных, импорт шаблона, невозможность сравнения единственного учебника и восстановление демо. Проход завершился успешно; ошибок JavaScript не зарегистрировано.

Точная длительность последнего автоматизированного прохода сохранена в поле `walkthroughSeconds` файла `artifacts/e2e.json`; она включает сохранение снимков и выгрузки файлов. Это длительность автоматизированных действий на компьютере разработки, **не время человеческого выступления и не тест производительности**. Устное выступление на 3 минуты участник ещё должен отрепетировать самостоятельно. Подробные отметки и данные экспортированного отчёта: `artifacts/e2e.json`; повторяемый сценарий: `scripts/e2e.mjs`. Для запуска проверки нужен работающий dev-сервер и браузер Chrome (`CHROME_PATH` при нестандартном расположении) либо установленный браузер Playwright.

Резервные материалы: `artifacts/OQY-pitch.pdf` — статичная презентация; `artifacts/e2e-overview.png`, `artifacts/e2e-books.png`, `artifacts/e2e-plan.png` — сохранённые результаты автоматизированной проверки на синтетическом наборе. При показе снимков называйте их сохранёнными результатами.
