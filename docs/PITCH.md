# Защита OQY — сценарий на 3 минуты

Время 3 минуты выбрано для подготовки: длительность выступления организаторами не указана. При другом лимите сократите вступление и оставьте путь «данные → сложная тема → план → проверка».

## Перед выходом

1. Выполнить `npm run build`, затем `npm run preview`.
2. Открыть приложение по адресу Vite и `/pitch.html` в соседней вкладке.
3. Убедиться, что загружен демонстрационный набор и видна отметка синтетических данных.
4. Подготовить `public/data/template.xlsx` и `public/data/template.csv` для показа формата и `public/data/demo.csv` для повторной загрузки.
5. Проверить запуск на том ноутбуке, с которого идёт защита. Не обновлять зависимости перед выходом.
6. Если приложение временно недоступно, открыть `public/pitch.html` напрямую. Это автономные слайды с описанием сценария, а не запись работающего продукта.

## Числа для выступления

На защите называйте только числа из текущего интерфейса и сохранённого отчёта проверки. Не называйте процент улучшения успеваемости, точность прогноза, экономию часов труда или причинный эффект учебника: эти результаты не измерялись.

## Репетиция и резерв

Этот файл — план репетиции, а не свидетельство уже проведённого выступления. Запустите таймер и пройдите таблицу на своей машине; зафиксируйте фактическую длительность. При задержке пропустите загрузку файла, сохранив сравнение и проверку суммы часов. Презентация автономна; используйте её при сбое приложения и прямо скажите, что показываете описание подготовленного сценария. Если есть сохранённый скриншот, обозначьте его как сохранённый результат.

Короткие ответы на вопросы находятся в [JURY_QA.md](JURY_QA.md).

## Проверка сценария на версии проекта

Текущий статус автоматизированных прогонов собранной версии — в [VALIDATION.md](VALIDATION.md). `artifacts/e2e.json` фиксирует сквозной сценарий, отдельная проверка новых функций охватывает Excel, поиск, сортировку и распределения. Длительность автоматизированных действий не является временем человеческого выступления и не измеряет педагогический эффект. Участнику нужно отрепетировать текст с таймером.

Резерв: `artifacts/OQY-pitch.pdf`, автономные шесть слайдов `public/pitch.html` и снимки `artifacts/e2e-*.png`. PDF и снимки должны быть обновлены для сдаваемой версии; при показе называйте их сохранёнными материалами.
