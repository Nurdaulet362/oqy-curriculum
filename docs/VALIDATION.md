- Сравнение учебников с одинаковым весом общих тем.

- Исходный план на 34 часа, сохранение целого бюджета при нескольких минимумах, квоты и начисление по дробным остаткам.

- CSV с BOM, разделителем `;`, кавычками; экспорт и обратный импорт.
- Отклонение лишних/пропущенных столбцов, невалидных чисел, дубликатов, пустых файлов и более 20 000 строк.
- Отказ от всего импорта при ошибке одной строки и защита экспорта от формул электронных таблиц.

Production-сборка (`npm run build`, включая `tsc -b`) завершена без ошибок. Эти проверки подтверждают перечисленные свойства реализации; они не доказывают педагогическую эффективность и не заменяют проверку пользовательского интерфейса.

## Формулы и границы выводов

Нормализованный балл строки: `100 × score / max_score`. Среднее рассчитывается по строкам. Освоение: доля строк с баллом `≥ 70%`. Для сравнения учебников сначала считается среднее каждой общей темы, затем среднее этих величин с одинаковым весом тем.

Сначала для каждой темы резервируется её минимум, по умолчанию один час. Остаток бюджета распределяется пропорционально весу.

```text
weight = currentHours × (1 + 3 × (100 − meanPercent) / 100)
remainingBudget = budget − sum(minimumHours)
quota = remainingBudget × weight / sum(weights)
recommendedHours = minimumHours + floor(quota) + remainderHour
```

Берётся целая часть квот; оставшиеся часы добавляются темам с наибольшими дробными остатками. При равенстве остатков сохраняется порядок тем: средний балл по возрастанию, затем название. Коэффициент **3** — явно выбранный приоритет сложных тем. Он не обучен на независимых результатах и не означает измеренный прирост знаний. Решение о плане остаётся за методистом.

В JSON-отчёте по каждой теме сохранены `allocation.minimumHours`, `weight`, `extraQuota`, `extraWholeHours` и `remainderHour`. Демонстрационный сценарий с минимумом 9 часов для дробей находится в `source.planningExample` сохранённого отчёта. Сумма минимумов 14, дроби получают 13 часов (9 + 4 + 0), весь план занимает 34 часа.

## Новые расчёты и пределы импорта

Распределения рассчитываются по нормализованным строкам: медиана и Q1/Q3 — Type 7, стандартное отклонение — деление на `n`, в процентных пунктах. Гистограмма имеет границы `[0,20)`, `[20,40)`, `[40,60)`, `[60,80)`, `[80,100]`. Распределение учебника охватывает все его результаты, а скорректированное сравнение — только общие темы с равным весом. Эти показатели включены в JSON, но не изменяют формулу часов или пять колонок CSV плана.

Excel: до 5 МиБ файла, 32 МиБ фактической распаковки, 2 000 ZIP-записей, 20 листов, 20 000 строк данных и 9 колонок на лист. Проверка ZIP учитывает фактические размеры и CRC, не только заявленные метаданные; XML-координаты проверяются до выделения массивов парсером. Worker ограничен 20 секундами и останавливается при отмене. Формулы, макросы и внешние связи не поддерживаются. Общая проверка CSV/Excel атомарна: ошибка не заменяет рабочий набор. Полная спецификация: [DATA.md](DATA.md).
