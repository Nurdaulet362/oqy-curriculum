# Данные и воспроизводимость

`public/data/demo.csv` — полностью синтетический демонстрационный набор, созданный для кейса Data-Driven Curriculum. В нём нет реальных учеников, школ, издательств или результатов обучения. Названия «Оқулық A» и «Оқулық B» вымышлены. Разница между ними заложена генератором и не доказывает эффективность какого-либо настоящего учебника.

## Генерация

Из корня проекта выполните:

```sh
node scripts/generate-demo.mjs
```

Команда перезаписывает только `public/data/demo.csv` и `public/data/template.csv` и печатает контрольные метрики. Генератор использует фиксированный seed `20261111` и целочисленный линейный конгруэнтный генератор. При повторном запуске файлы совпадают побайтно. Результат зависит от заданной сложности темы, синтетического уровня ученика, небольшого эффекта школы, заданного эффекта учебника по теме и случайного шума. Это сценарий демонстрации, а не обученная модель и не оценка реального образовательного эффекта.

Проверяются число строк и учеников, бюджет часов, отсутствие повторов `student_id + subject + topic` и попадание баллов в диапазон. Часы одинаковы для одной темы во всех строках: это часы учебного плана, а не сумма времени всех учеников.

## CSV и Excel для своего набора

`public/data/template.csv` содержит заголовок и шесть результатов одного вымышленного ученика по шести темам. Это пример формата, а не достаточная выборка для выбора учебника. Чтобы получить сравнение, добавьте результаты других учеников с другим учебником по общим темам.

| Колонка | Смысл | Пример |
| --- | --- | --- |
| `student_id` | Обезличенный стабильный ID ученика | `DEMO-001` |
| `school` | Название или обезличенный код школы | `Школа 01` |
| `grade` | Класс | `7` |
| `subject` | Предмет | `Математика` |
| `topic` | Согласованное название темы | `Дроби` |
| `textbook` | Учебник, использованный учеником | `Оқулық A` |
| `score` | Набранный балл, от 0 до `max_score` | `10` |
| `max_score` | Положительный максимальный балл | `20` |
| `hours` | Положительное целое число часов по теме | `6` |

Для CSV используйте UTF-8, строку заголовков и десятичную точку в числах. Excel-шаблон `public/data/template.xlsx` содержит ту же схему: первая строка — 9 заголовков, ниже — текстовые или числовые значения. ID с ведущими нулями (`001`) задавайте текстом: числовое значение Excel с форматом отображения `000` не сохраняет исходные нули как часть ID. Не добавляйте ФИО, телефоны, адреса, даты рождения и другие идентификаторы детей. Одна запись — один итоговый результат ученика по теме и предмету; повторные попытки предварительно приведите к одному результату по явно выбранному правилу. Для сопоставления учебников нужны одинаковые темы, сравнимые тесты и сопоставимые условия проведения.

## Границы выводов

- Низкий балл — сигнал для проверки темы, материалов и условий обучения; он не устанавливает причину.
- Сопоставление по общим темам уменьшает влияние разного состава тем, но не устраняет различия учителей, школ, учеников и исходной подготовки.
- Предложение часов — прозрачная эвристика распределения заданного бюджета. Его должен проверить методист с учётом обязательной программы.
- Измеренные значения характеризуют только этот синтетический набор. Рост результатов обучения на реальных школьниках не измерялся.

## Ограничения импорта

CSV и Excel — до 5 МиБ и 20 000 строк данных; CSV должен быть в UTF-8. Для одной пары «предмет + класс» поддерживается до 200 тем и 20 учебников. Это явные пределы браузерного прототипа; набор вне пределов отклоняется целиком до замены текущих данных.

`student_id` — глобальный ID в рамках одного набора-снимка: ему должны соответствовать одна школа и один класс. При объединении выгрузок школ добавьте к локальному ID код школы. Продольные данные по разным классам/годам требуют отдельной схемы; текущий формат их не поддерживает. Названия нормализуются Unicode NFC, невидимые управляющие символы и повреждённый UTF-8 отклоняются.


## Чтение Excel

Поддерживается `.xlsx`; `.xls` и `.xlsm` необходимо пересохранить как обычный `.xlsx` или CSV. Одна книга с несколькими листами открывает выбор: импортируется только выбранный лист, без объединения. Отмена и ошибка проверки не заменяют текущий набор. Чтение выполняется локально в Web Worker с ограничением 20 секунд; при завершении, отмене или ошибке worker прекращает работу.

Пределы книги: 20 листов, 2 000 ZIP-записей, суммарно 32 МиБ **фактически распакованных** данных. На каждом листе — не более 20 000 строк данных плюс заголовок и 9 колонок A–I; лишнее оформление за этими пределами также может привести к отказу. Ограничения проверяются для книги, поэтому удалите ненужные листы, даже если импортировать их не собираетесь.

Формулы отклоняются во всей книге; сохранённый результат формулы не используется. Скопируйте ячейки и вставьте только значения. Макросы, внешние связи, даты, логические значения и ошибки ячеек не поддерживаются. Проверка выбранного листа использует те же правила схемы, диапазонов, дублей, ID и часов, что CSV. Неверный набор отклоняется целиком.

## Описательная статистика

Каждое наблюдение — нормализованный результат `100 × score / max_score`. Один ученик может дать несколько наблюдений по разным темам. Медиана, Q1/Q3, минимум, максимум и стандартное отклонение рассчитываются для выбранной когорты, отдельных тем и всех результатов каждого учебника.

Квартили — линейная интерполяция Type 7: индекс `(n − 1) × p` для `p = 0.25, 0.5, 0.75`. Стандартное отклонение — `sqrt(sum((x − mean)²) / n)`, в процентных пунктах; это описание загруженных наблюдений, без оценки генеральной совокупности. Для одного наблюдения оно равно нулю, для пустого набора показатели равны `null`. Гистограмма: `[0,20)`, `[20,40)`, `[40,60)`, `[60,80)`, `[80,100]`; значение 100 включается в последний диапазон.

Распределение учебника по всем его строкам отличается от скорректированного среднего сравнения: последнее использует только общие темы с одинаковым весом. JSON-отчёт включает `distribution` для когорты, тем и учебников. JSON также содержит параметры распределения часов по каждой теме, включая заданный минимум и результат округления. CSV плана содержит название темы, средний балл, текущие и предложенные часы и разницу. Поиск и сортировка таблицы меняют только отображение; отчёт и план используют весь набор, выбранный глобальными фильтрами предмета, класса и школы.
