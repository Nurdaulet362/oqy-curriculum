# Интерфейс OQY
Рабочая поверхность методиста: аналитический кабинет, основной шаг — загрузить CSV и принять решение по темам. Направление: спокойный редакционный интерфейс, тёплая бумага, тёмно-зелёная навигация, лаймовый акцент; графики показывают реальные агрегаты текущего набора. Источник требований — локальный кейс и фото.
Иерархия: источник и фильтры → показатели → темы и рекомендация → сравнение → план → выгрузка. Виды 1440x900 и 390x844. Sidebar переходит в горизонтальную навигацию, таблицы прокручиваются внутри контейнера.
Состояния: загрузка демо; пустой фильтр с возвратом; некорректный CSV с сохранением предыдущего набора; неполное сравнение с предупреждением; успешный импорт/экспорт с сообщением. Вход и разрешения не применимы — локальная обработка без аккаунта и сервера.
