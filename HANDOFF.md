# OQY — готовность к защите

Цель: кейс 1 Zhambyl Hub — анализ тем, сравнение учебников и распределение часов. Дедлайн: сегодня, 11 ноября 2026, Asia/Almaty; точное время неизвестно. Участник сам заполняет и отправляет форму.

Приватный репозиторий: https://github.com/Nurdaulet362/oqy-curriculum, ветка `main`. Точная версия: `git rev-parse HEAD`; история удалённого репозитория фиксирует сдаваемые файлы.

## Запуск

Node.js ≥22.18: `npm ci`, затем `npm run dev`, открыть http://127.0.0.1:5173. Собранная версия: `npm run build && npm run preview`, адрес http://127.0.0.1:4173.

Комплект без npm: распаковать `release/OQY-demo.zip`, перейти в папку OQY и выполнить `python3 start.py` (Windows — `python start.py`). Нужен Python 3; интернет не нужен. Остановить Ctrl+C. Исходный архив: `release/OQY-source.zip`.

## Материалы

- `artifacts/OQY-pitch.pdf` — 6 слайдов; `public/pitch.html` — автономная версия.
- `docs/PITCH.md` — текст выступления и сценарий на 3 минуты.
- `docs/JURY_QA.md` — ответы на вопросы.
- `artifacts/demo-report.json`, `artifacts/demo-plan.csv` — сохранённые вычисленные результаты.
- `artifacts/e2e-*.png` — запасные изображения. Называть их сохранённой демонстрацией.
- `docs/CASE.md`, `docs/DATA.md`, `docs/VALIDATION.md`, `docs/REVIEW.md` — требования, данные, измерения и ревью.

## Проверено

18 unit-тестов, production-сборка, 11 этапов браузерного сквозного сценария. CSV с ошибкой отклоняется целиком, предыдущие данные сохраняются. Бюджет 34/40 часов совпадает с суммой плана. Демо: 144 синтетических ученика, 864 результата, 6 тем, 3 условные школы, 2 вымышленных учебника. Среднее 67,55%; при бюджете 34 дроби 6→7 часов, уравнения 7→8. Фактические детали: `artifacts/e2e.json` и `artifacts/benchmark.json`.

## Ограничения и расходы

Сравнение описательное, причинный эффект учебников не установлен. Распределение часов — прозрачная эвристика, не норматив и не прогноз роста знаний. Реальных школьных данных нет. Устная репетиция участником ещё нужна; автоматическая проверка кликов её не заменяет.

Приложение не требует секретов, сервера, GPU или платных API. Платных API/аренды не запускали; подтверждённых списаний за них нет. Локальные серверы можно завершить Ctrl+C. Приватную ссылку жюри увидит только при предоставленном доступе; репозиторий публичным не делать.

## Ближайшее действие

Открыть демо, прочитать `docs/PITCH.md` вслух с таймером и отправить форму организаторов самостоятельно. Если требуется код — приложить исходный ZIP или предоставить жюри доступ к приватному репозиторию. Приём заявки организаторами не подтверждён: форму отправляет участник.
