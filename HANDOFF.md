# OQY — передача проекта для защиты

Кейс 1 Zhambyl Hub: анализ тем, сравнение учебников и распределение часов. Дедлайн со слов участника — 11 ноября 2026, Asia/Almaty; точное время неизвестно. Участник сам заполняет и отправляет форму.

Приватный репозиторий: https://github.com/Nurdaulet362/oqy-curriculum, ветка `main`. Версия исходников: `git rev-parse HEAD`. Репозиторий должен оставаться приватным; жюри потребуется доступ или исходный архив.

## Что добавлено

- Импорт CSV и Excel `.xlsx`; отдельный worker читает книгу, для нескольких листов пользователь выбирает один. Ошибка или отмена сохраняет предыдущие данные.
- TanStack Table: поиск тем, числовая и текстовая сортировка, счётчик строк, очистка и состояние пустого поиска. Фильтр таблицы не меняет полный итог и экспорт плана.
- Описательная статистика: медиана, квартили Type 7, минимум/максимум, стандартное отклонение с делителем `n`, гистограмма по пяти диапазонам. Эти показатели относятся к результатам по темам, а не к уникальным ученикам.
- Сохранены исходные расчёты сравнения на общих темах и планирования с точным бюджетом. Подробности: [docs/FEATURE-UPDATE.md](docs/FEATURE-UPDATE.md).

## Запуск и материалы

Node.js ≥22.18: `npm ci`, затем `npm run dev`. Production: `npm run build && npm run preview`.

Комплект без npm: распаковать `release/OQY-demo.zip`, перейти в папку OQY и выполнить `python3 start.py` (Windows — `python start.py`). Нужен Python 3; интернет не нужен. Остановить Ctrl+C. Исходники: `release/OQY-source.zip`.

- `public/pitch.html` — шесть автономных слайдов; `artifacts/OQY-pitch.pdf` — актуальный PDF релиза.
- `docs/PITCH.md`, `docs/JURY_QA.md`, `docs/SUBMISSION.md` — выступление, ответы и текст для формы.
- `public/data/template.csv`, `public/data/template.xlsx` — шаблоны входных данных.
- `artifacts/demo-report.json`, `artifacts/demo-plan.csv` — актуальные сохранённые результаты; при показе снимков называйте их сохранённой демонстрацией.
- `docs/CASE.md`, `docs/DATA.md`, `docs/VALIDATION.md` — требования, данные, статус проверки.

## Статус проверки релиза

**Локальные проверки пройдены:** 51 unit-тест, 45 проверок новых функций, 11 этапов E2E, 8 строгих браузерных сценариев, 27 проверок дизайна, 3 проверки упаковки. 19 автоматических сканов доступности (10 общих и 9 для новых состояний) — без нарушений проверенных правил; ошибок JavaScript нет. Команды и границы проверки: `docs/VALIDATION.md`. Старые `REVIEW.md`, `STRICT-AUDIT.md` и `DESIGN-UPDATE.md` — история предыдущих проверок, а не заключение по Excel и новым таблицам. PDF, сохранённые результаты, снимки и ZIP обновлены для передачи. Версия и хеши итоговой сборки находятся в `release/OQY/VERSION.json` и `MANIFEST.json`.

Демо: 144 синтетических ученика, 864 результата, 6 тем, 3 условные школы, 2 вымышленных учебника; исходный бюджет 34 часа. Данные не являются доказательством эффективности обучения.

## Ограничения и сдача

Excel: до 5 МиБ, 32 МиБ фактической распаковки, 2 000 ZIP-записей, 20 листов, 20 000 строк данных и 9 колонок на лист; worker — до 20 секунд. Формулы заменять значениями, ID с ведущими нулями сохранять как текст. Полный формат: `docs/DATA.md`.

Сравнение описательное. План — эвристика для методиста, не норматив и не прогноз роста знаний. Приложение не требует сервера, секретов, GPU или платных API. Устную защиту участнику ещё нужно отрепетировать с таймером.

Перед сдачей открыть готовый архив на машине защиты, проверить финальные отчёты, прочитать `docs/PITCH.md` и отправить форму самостоятельно. Наличие репозитория не подтверждает приём заявки.
